# 超级 AI 员工产品级 Demo 交付说明

## 产品定位

这是一套可运行、可演示、可保存数据、可打包交付的单工作区 AI 员工系统。它复现参考视频的核心业务结构，而不是把“生成一个视频”误当成全部产品。

```text
业务目标 → AI 员工规划与执行 → 人工验收 → 成果资产
        → 视频/分镜制作 → 账号选择 → 发布排期
```

## 10 分钟验收路线

1. 阅读首次使用引导，点击“开始使用超级员工”。
2. 在 `Agent` 中选择“小策”，创建并执行一项内容任务。
3. 检查步骤输出并人工确认成果。
4. 在 `素材管家` 中找到自动沉淀的成果。
5. 将成果送往“创意视频”，生成脚本与四个场景。
6. 下载带基础音轨的本地 WebM，或确认制作方案。
7. 将另一份成果送往“发布管家”，选择演示账号和计划时间。
8. 打开 `系统控制台`，检查任务数量、供应商状态和操作审计。
9. 下载全量 JSON 数据备份。

## 已经是真功能

- React 前端通过 REST API 使用 FastAPI 后端，不依赖浏览器假数据。
- 员工任务、工作流、成果资产、制作任务、账号和排期均写入 SQLite。
- 任务和制作方案有明确状态流转，并保留人工验收节点。
- 浏览器可生成并下载真实 WebM 文件。
- 系统控制台可修改工作区、查看诊断、审计成功写操作并导出数据。
- Docker Compose 可冷启动前后端，并通过数据卷持久保存 SQLite。

## 明确的演示边界

- 内置语言执行器输出稳定的演示结果，不等同于已接入商业大模型。
- WebM 使用 Canvas、MediaRecorder 和基础音轨，证明媒体交付链路，不代表商业视频质量。
- 演示账号不保存密码、Cookie 或令牌。
- 发布排期只保存在系统中，不会自动登录或向外部平台发布。
- 当前是单工作区本地部署，不包含多租户、计费、企业 SSO 和公网运维。

这些边界不影响产品演示，但在正式商用前必须补齐真实供应商合同、平台 OAuth、身份与权限、队列、监控、合规和云端部署。

## 给别人使用

Windows 使用者安装并启动 Docker Desktop 后：

1. 从 GitHub 下载 ZIP 并解压；
2. 双击根目录 `start-demo.bat`；
3. 浏览器打开 `http://127.0.0.1:8080`；
4. 使用完双击 `stop-demo.bat`。

停止服务不会删除数据。详细说明见 `docs/PACKAGING.md`。
