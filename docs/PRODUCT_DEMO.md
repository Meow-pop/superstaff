# Superstaff v0.5 产品验收说明

## 产品定位

这是一个可运行、可保存数据、可私有部署和可继续扩展的单工作区 AI 员工产品。默认规则执行器保证没有模型也能使用；本地 Ollama 用于提升实际脚本与工作流质量。

## 10 分钟验收路线

1. 启动系统并完成首次使用引导。
2. 在 `Agent` 中给内容员工创建并执行任务，人工验收结果。
3. 在 `素材管家` 中找到自动沉淀的成果并送往“创意视频”。
4. 在视频工作室设置受众、目标、画幅、风格、节奏和品牌色。
5. 生成脚本与分镜，修改任意镜头的旁白、景别、运动或转场。
6. 打开“质量与交付”，检查时长、品牌、行动引导和 AI 标识。
7. 生成本地 WebM，并导出包含完整制作参数的 JSON 制作包。
8. 打开 `系统控制台` 检查本地模型、能力适配器、操作审计和备份。

## 已经是真功能

- 前端通过 REST API 使用 FastAPI 后端，业务数据写入 SQLite。
- 员工任务、工作流、成果、制作任务和发布计划有明确状态流转。
- 视频创作简报和逐镜头编辑会持久保存，旧数据库自动迁移。
- 浏览器会按照项目画幅、品牌色、风格和镜头时长生成真实 WebM。
- Ollama 模式会直接调用客户自己的本地模型，不经过 Dify 或云模型。
- Docker 冷启动后通过数据卷持久保存业务数据和模型权重。

## 当前边界

- 本地视频引擎擅长品牌化字幕、信息图和内容型短视频，不等同于 Runway/Veo 一类写实生成式视频基础模型。
- 当前本地声音是背景音轨，写实人物配音和数字人需要经过单独许可证审计的离线语音模块。
- 发布模块默认导出并人工上传；真实自动发布必须获得目标平台 OAuth/API 授权。
- 当前为本地单工作区，不包含公网多租户、计费、SSO 和云运维。

这些边界会在界面中明确显示，不会把演示能力包装成已经完成的外部能力。
