# 视频目标系统复现范围

## 目标定义

本项目的产品目标是复现用户提供的视频中的“AI 超级员工系统”。学习前端、后端和 AI 工程是开发过程的伴随目标，不是产品页面中的功能，也不改变目标系统的业务形态。

参考视频：`654af773d24b16d58f5920ea2cb51439.mp4`

## 从视频识别出的产品结构

### 总控首页

- 紫蓝色 `AI 超级员工系统` 横幅。
- 三个主要入口：`Agent 智能体`、`自动工作流`、`一键追爆`。
- 企业大脑、专属智能体训练、短视频矩阵、多渠道获客等能力卡片。
- 左侧固定业务导航，顶部显示账号、到期时间、点数和通知。

### Agent 与工作流

- 创建和管理专属 Agent。
- 为 Agent 设置角色、能力、任务和执行规则。
- 把重复业务编排成自动工作流。
- 任务中心记录运行状态、步骤和交付结果。

### 内容与视频矩阵

- 素材管理、文案生成和多场景剪辑。
- 多场景、多字幕风格和画面素材组合。
- 数字人口播、声音、形象和视频生成。
- 抖音、小红书、快手、视频号等多账号管理。
- 发布任务、互动记录、评论和粉丝列表。

### 获客与销售线索

- 按关键词和平台采集公开互动线索。
- 设置采集、私信触达和运行规则。
- 按城市、行业、关键词检索企业。
- 保存企业名称、联系人、电话、营业时间和地址。
- 搜索记录、线索管理和后续客户跟进。

## 我们的复现原则

1. **先形似再逐个接通**：先完成统一壳、首页和模块信息架构，避免做成另一个产品。
2. **每个阶段必须有真功能**：模块可以暂未开放，但已开放模块不能只是静态截图。
3. **先复现工作闭环**：Agent 接任务、执行、验收和成果沉淀是所有后续模块的底座。
4. **外部平台遵守授权边界**：账号发布、评论采集、私信和企业数据只能通过正式授权或合规数据源接入。
5. **视频是重要模块，但不是唯一模块**：质量逐步提升，同时推进工作流、矩阵和获客。

## 分阶段实现

| 阶段 | 界面范围 | 可用能力 |
| --- | --- | --- |
| M1 已完成 | 视频同款系统壳、总控首页、完整模块树、Agent 页面 | 创建任务、生成计划、执行、成果、人工验收、SQLite 持久化 |
| M2 进行中 | 自动工作流、任务中心、成果资产 | 已完成工作流编排与运行记录；下一步打通成果跨模块流转 |
| M3 | 内容创作、短视频矩阵、账号管理 | 文案、素材、视频、账号与发布任务统一管理 |
| M4 | 数字人、形象、声音与创意视频 | 供应商适配层、生成任务、成本和失败重试 |
| M5 | 关键词拓客、企业线索、智能客服 | 合规检索、线索库、跟进任务和客服工作流 |

## 当前代码如何承接目标

- `frontend/` 负责复现视频中的系统界面和交互。
- `backend/` 负责所有模块共享的员工、任务、状态、成果和数据。
- `executors/` 把 Agent 能力、模型和工具接入任务闭环。
- 原有静态原型中的工作流、素材、视频、账号和客户能力会逐步迁入正式版，而不是废弃。
- `docs/` 单独承载学习路线和面试讲解，不进入用户产品导航。
